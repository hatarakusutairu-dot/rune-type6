# スライド画像置き場

ここに PNG を置くと、対応するフェーズで自動的に投影されます。
ファイルが無いフェーズは、既存のテキスト版スライドにフォールバックします。

## ファイル名と対応フェーズ

| ファイル名 | フェーズ |
|------------|----------|
| `stage0_rules.png` | ルール |
| `stage0_theme.png` | テーマ「他者理解」 |
| `stage0_flow.png` | 今日の流れ |
| `stage1_explain_1.png` | タイプ解説：コンペティター |
| `stage1_explain_2.png` | タイプ解説：アチーバー |
| `stage1_explain_3.png` | タイプ解説：ソーシャライザー |
| `stage1_explain_4.png` | タイプ解説：エクスプローラー |
| `stage1_bridge.png` | ブリッジ（ワーク1→ワーク2） |
| `stage2_explain_1.png` | タイプ解説：アタッカー |
| `stage2_explain_2.png` | タイプ解説：ガーディアン |
| `stage2_explain_3.png` | タイプ解説：アナリスト |
| `stage2_explain_4.png` | タイプ解説：ブースター |
| `stage3_share.png` | 共有タイム |
| `stage3_comment.png` | 感想を一言で |
| `stage3_closing.png` | まとめ |

## 推奨フォーマット

- **PNG**（劣化なし、テキストがクッキリ）
- **解像度 1920×1080** 以上（16:9）
- **背景込み**（ダーク背景を画像に焼き付けてOK、透過不要）

JPG / WebP も読めますが、PNG 推奨。
