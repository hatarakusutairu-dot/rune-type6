# カスタムリアクション画像置き場

ここに PNG を入れると、生徒・講師のリアクションボタンに追加されます。

## 使い方

1. **PNG をこのフォルダに置く**
   - 例：`wakwak.png` `fire.png`
   - 推奨：256×256 透過 PNG、50KB 以下

2. **`manifest.json` に登録する**
   ```json
   {
     "items": [
       { "key": "wakwak", "label": "ワクワク" },
       { "key": "fire",   "label": "炎" }
     ]
   }
   ```
   - `key` = ファイル名（拡張子なし）
   - `label` = ボタンの説明（hover で出る）

3. 反映するには `npm run build` してブラウザリロード（ハードリロード `Ctrl+Shift+R`）

## 画像の作り方ポイント

- **背景は透過**（PNG のアルファチャネル）
- **正方形 256×256**（Retina対応）
- **ファイルサイズは小さく**（〜50KB 推奨。多くても 100KB 以下）
- 中身は中央寄せにすると見栄えがいい
